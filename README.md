# Nifte Mod

A client-side quality-of-life mod for Minecraft **26.2** (Fabric). Every feature can be turned on or off from the in-game settings screen (`N` by default, or through Mod Menu).

This mod is **client-only**. It does not need to be installed on servers.

## Requirements

- Minecraft 26.2
- Fabric Loader 0.19.3+
- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Cloth Config](https://modrinth.com/mod/cloth-config)
- [Mod Menu](https://modrinth.com/mod/modmenu) (recommended, for the config button)

## Features

### HUD

- FPS counter with position, scale, and color
- Armor durability display
- Potion effect timers on status icons

### Camera

- Skip front-facing third person
- Zoom (hold or toggle)
- Fullbright

### Inventory

- Scroll items between slots with the mouse wheel
- Sort containers with the pick-block button
- Improved item dragging
- Drop confirmation
- Move around while containers are open

### Equipment

- Auto totem refill
- Auto elytra swap
- Auto tool swap
- Auto weapon swap
- Stop tools from breaking

### Building

- Bedrock-style bridging
- Fast block placement
- Hand restocking for blocks and liquid buckets
- No block-breaking delay

### Crafting

- Show all recipes in the recipe book
- Scroll recipe book pages with the mouse wheel
- Keep the inventory centered when the recipe book is open
- Instant craft from the recipe book

### UI

- Numerical ping in the player list
- Hunger restored shown on food names and tooltips
- Shulker box contents in tooltips
- Optional advancement and recipe toast filters

### Particles

- Toggle individual particle types on or off
